# Current OPERATE benchmark

This directory is the public Core and Lite index. It lists the current
769 Full scenarios and 193 Lite scenarios. Scenario YAML files live under
`scenarios/<domain>/...`.

Runtime binaries (NREL/OEDI profiles, M5 tables, backend archives) come
from the Hugging Face companion and install into `operate_data/` and `works/`.
They are not qualification ledgers and do not overlay this directory.
